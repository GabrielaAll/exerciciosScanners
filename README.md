# 📚 Atividade com Scanner e Operações em Java

Este repositório contém os exercícios práticos desenvolvidos para treinar a leitura de dados com a classe `Scanner`, manipulação de variáveis, operações matemáticas e estruturas condicionais em Java.

---

## 🛠️ Descrição dos Exercícios

1. **Nome e Idade (Próximo Aniversário):** 
   * Solicita o nome e a idade do usuário, calcula a idade do próximo ano somando `+ 1` e exibe uma mensagem personalizada formatada.
2. **Operações Matemáticas:** 
   * Recebe dois números inteiros e calcula e exibe a soma (`+`), subtração (`-`), multiplicação (`*`), divisão inteira (`/`) e o resto da divisão (`%`).
3. **Sistema de Notas:** 
   * Lê a nota de uma aluna e utiliza estruturas condicionais (`if`, `else if`, `else`) para classificar a situação em: **Aprovada** (7 ou mais), **Recuperação** (entre 5.0 e 6.9) ou **Reprovada** (abaixo de 5.0).
4. **Tabuada de 1 a 10:** 
   * Lê um número inteiro do usuário e utiliza um laço de repetição (`for`) para calcular e exibir a tabuada completa de 1 a 10.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Java
* **Entrada de Dados:** `java.util.Scanner`
